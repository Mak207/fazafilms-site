# Музыка ролика «Хоровод»

- произведение: «Во поле берёза стояла»;
- композиция: русская народная хороводная мелодия;
- версия: та же синтезированная инструментальная аранжировка, что использовалась в ролике с 509 линиями;
- темп: 80 BPM;
- характер: щипковые струны с тремоло, бас и деревянная перкуссия;
- внешние записи и чужая коммерческая фонограмма не использовались;
- отдельный файл доставки: PCM 24-bit / 48 kHz / stereo WAV;
- звук внутри браузерного MP4: AAC около 320 kbit/s для совместимости браузеров.

Исходный файл аранжировки версии 509 был сохранён как PCM 16-bit. Файл WAV на странице
переведён в контейнер PCM 24-bit без заявления о восстановлении отсутствовавшей в исходнике
разрядности. Для настоящего нового 24-битного звукосинтеза потребуется повторный экспорт
аранжировки из исходной музыкальной сессии.
