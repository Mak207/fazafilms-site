# Посетители парка

Набор содержит 20 исходных персонажей Avatar Studio / Microsoft Rocketbox и по пять вариантов одежды. В сцене появляются 100 посетителей. Это 20 базовых лиц с вариантами внешности и одежды; сто уникальных исходных лиц не заявляются.

## Файлы

- `assets/*.crowd.glb` — двадцать подготовленных моделей со скелетами и анимациями.
- `avatar_manifest.json` — масштаб, контрольные суммы, параметры одежды, состав моделей и источник каждого персонажа.
- `sources_manifest.json` — закреплённые версии и контрольные суммы исходных моделей.
- `crowd_factory.js` — создание экземпляров с общими геометриями и текстурами, выбор одежды, скелетная анимация и освобождение ресурсов.
- `THIRD_PARTY_NOTICES.md`, `LICENSE_AVATAR_STUDIO` — лицензии исходного семейства Microsoft и конверсии Avatar Studio.

Модели загружаются через общий GLTFLoader парка с MeshoptDecoder. Они требуют `EXT_meshopt_compression` и `EXT_texture_webp`. Второй renderer, камера или независимый цикл кадров не создаются.

Фаза шага задаётся расстоянием, которое реально прошёл посетитель в симуляции. Остановка и поездка в кабине используют положение ожидания. Частота обновления дальних скелетов уменьшается; их положение остаётся связано с общим расчётом маршрутов.

Масштаб и оттенки одежды вариативны. Менять масштаб экземпляра после его создания без пересчёта длины шага нельзя. Управление маршрутом выполняет модуль `../engine/`, а не фабрика персонажей.
