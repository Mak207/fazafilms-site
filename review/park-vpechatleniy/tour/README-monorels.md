# Монорельс — рабочий челночный маршрут и происхождение

Актуальная кандидатная сцена использует **открытый челночный маршрут к существующей северо-западной площадке на отметке Y = 16,65 м**, показанной пользователем. Площадка и две ведущие к ней лестницы подтверждены геометрией CAD. Её использование для посадки, местный проём в ограждении и трасса остаются **рабочим сценовым решением**. Пассажирское назначение этой площадки в исходном проекте не установлено.

Состояние документации: 24 ноября 2026 года. Геометрические и численные проверки выполнены; **интегрированная сцена прошла 183 из 183 браузерных проверок в Microsoft Edge на настольном и мобильном экранах**, без ошибок JavaScript, HTTP и запросов. Отдельная узкая регрессия уведомлений финальной пачки также завершена: **40/40, PASS**, без ошибок JavaScript, HTTP и запросов; Edge закрыт после проверки. Геометрия маршрута и модуль монорельса не менялись. Документация зафиксирована для локальной кандидатной версии; публикация не выполнялась. Машинный реестр: [monorail-source.json](assets/monorail-source.json). Подробные координаты, опоры и источники: [monorail-station-evidence.json](assets/monorail-station-evidence.json).

## Актуальная трасса и движение

| Параметр | Текущее значение |
|---|---|

| Конфигурация, подключённая в viewer | `MONORAIL_ROUTE_CONFIG` из `tram-system.js` |
| Тип пути | Открытый челночный маршрут |
| Длина пути | 212,815708 м, примерно 212,8157 м |
| Верх направляющей | Y = 16,60 м на основной трассе; Y = 15,85 м у площадки |
| Профиль подхода | Плавное снижение на 0,75 м за 25 м; максимальный уклон 0,045 |
| Южные повороты | Радиус 22,5 м |
| Опоры | 19; основания на реальных перекрытиях Y = 7,2 и 13,2 м |
| Вагоны | Два экземпляра исходной модели, длина каждого 12 м |
| Интервал | Центры через 13,5 м по пути; номинальный промежуток кузовов 1,5 м |
| Движение | 3 м/с; совместная смена направления без разворота моделей на месте |
| Остановки | 8 с у площадки, 4 с у другого конца |
| Посадка | В одном остановочном положении стыкуется только первый вагон |

Маршрут проходит по восточной прямой, огибает южную часть экспозиции и поднимается вдоль западной стороны к северо-западной площадке. Последний подход соединён плавной кривой. Два вагона движутся с общим направлением и интервалом; в крайних положениях они не переставляются и не разворачиваются на 180 градусов. Продольный наклон следует профилю направляющей.

Сохранена одна центральная направляющая: бетонная балка 0,95 × 0,72 м, металлическая рабочая поверхность 0,30 × 0,06 м и тонкая линия света снизу. Основания 19 опор определяются по существующим перекрытиям через `supportFloorHeight(x,z)`; фактические записи доступны через `getSupportRecords()`. Старые координаты 22 опор к текущей трассе не относятся.

Над основной антресолью Y = 13,2 м нижняя грань балки даёт около 2,62 м. На последнем подходе есть низкая зона X ≈ −15,84…−14,88; Z ≈ −62…−54 с просветом 1,87…2,08 м. Посетителей необходимо исключать из этой зоны по фактическим препятствиям `getCollisionObstacles()` с учётом их высоты. Это ограничение остаётся частью рабочей раскладки.

## Существующая площадка и локальный проход

Подтверждённый настил — `A-FLOR__f4cc95ff`, исходный объект `Перекрытие ATR_ВН_ОТ_Пол_Керамо_56ecded`. Его верх находится на Y = 16,65 м; границы основной плиты: X = −34,884342…−16,184341; Z = −80,292366…−61,167366 м, площадь около 356,029 м². Лестницы `_03d5fb0` и `_45104e1` соединяют этот узел с антресолью Y = 13,2 м.

Вагон подходит бортом к восточной кромке. В остановке его центр расположен приблизительно в (−14,889823; 15,85; −68,5), боковой зазор — 0,15 м. Смещение принятого пола салона на +0,8 м относительно направляющей даёт отметку 16,65 м. **Это визуальная калибровка: отдельный пол салона и подтверждённая дверь в GLB не выделены.**

Рабочая калитка шириной 1,2 м задаётся `MONORAIL_BOARDING_GATE` в ограждении `Ограждение__7f7f7fff`: X = −16,19…−16,13; Y = 16,6501…17,80; Z = −69,10…−67,90 м. Общий модуль `cad-openings.js` вычитает только этот местный объём из полигонов, сохраняя все внешние фрагменты длинных панелей. Тот же метод применяется к проходу на переход к ледоколу. Исходный `park.glb` не изменён.

Площадка не отождествляется с пассажирской станцией ЦФО, видимой в ролике: совпадение назначения и проектных координат не доказано. Отдельная реконструированная плита ЦФО исключена из конечной сцены; вариант сохранён только в рабочих материалах.

## Модуль и интеграция

`tram-system.js` — ES-модуль для Three.js r180. `createTramSystem({scene, modelUrl, loader, routeConfig, onState, supportFloorHeight})` получает существующий GLTFLoader с MeshoptDecoder. Viewer передаёт экспорт `MONORAIL_ROUTE_CONFIG`. Оставшийся `DEFAULT_ROUTE_CONFIG` относится к совместимому прежнему конструктору замкнутой петли и не является текущей конфигурацией viewer.

Кроме управления движением, камерами сопровождения и видом из вагона, модуль предоставляет `getStationPose()`, `getSupportRecords()`, `getCollisionObstacles()`. В состоянии отражаются `routeMode`, направление, остановка, интервал и `boardingVehicle`. Собственный DOM и цикл кадров модуль не создаёт. При ошибке загрузки настоящего GLB подменные вагоны в сцену не добавляются.
