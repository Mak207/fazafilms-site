# Контактный опыт A / B / C — итог 22.11.2026

## Решение

**C принят как кандидат для ровного пола:** одинаковая текущая модель с подготовленным Native Walk и ограниченный общий подъём root по всем weighted вершинам стоп. В единственном повторном прогоне после исправления измерителя C убрал проникновение на всех 480 шагах обоих актёров. Максимальный подъём — **11,2197 мм у Emma и 18,4100 мм у Ethan**. Предел 20 мм и сглаживание опускания 80 мс не изменялись. Локальные преобразования суставов и координаты XZ сохранены.

Готовый FootIK B также устраняет проникновение в полном наборе проверяемых вершин, однако добавляет зазор над полом и у Ethan увеличивает движение центра подошвы в эвристической фазе опоры. Поэтому B остаётся сравнительным экспериментом. C — собственная простая геометрическая коррекция, не готовая библиотека, не IK и не foot locking.

Рабочая выставка v42 не заменена. Результат относится к двум циклам Walk на плоскости; перенос в навигацию, переходы между движениями, повороты и производительность выставочного runtime этим опытом не подтверждены.

## Сопоставимые варианты

| Вариант | Исходные данные | Обработка после анимации |
|---|---|---|
| A | Текущий walking-woman / walking-man + Contact · Walk | Нет |
| B | Та же геометрия, клип и физическое время | Закреплённый hh-hang FootIK 0.6.3 |
| C | Та же геометрия, клип и физическое время | Общая world-Y трансляция всего root по полному min обуви |

Использованы подготовленные `assets/emma-native-motions.glb` и `assets/ethan-native-motions.glb`, точный клип `UPF · Walk`. Это экспортированные для текущего rig движения; слово native не означает совместимость исходных и текущих скелетов. Исходный клип сохранён как `Contact · Raw source Walk` и проверен на неизменность.

Из Hips XZ вычитаются первая позиция и линейное перемещение за цикл. Y и остаточное покачивание сохраняются. Время всех треков пересчитано одинаково; cubic tangents учитывают новые единицы времени. Holder движется непрерывно по извлечённому мировому XZ-вектору. Один физический шаг — 1/60 с, на актёра 480 шагов / 8 с, включая старт без отброшенного warmup.

## Формула C и исправленный дефект измерения

Цель: `target = min(0.02, max(0, -fullWeightedShoeMinY))`. Превышение требуемых 20 мм считается провалом; предел не поднимается. Вверх подъём выполняется сразу. Вниз: `target + (previous-target) * exp(-dt/0.08)`. Постоянная добавочная высота равна нулю; при target=0 остаток сохраняется только на время плавного опускания.

Первый вариант C использовал 64 точки. Он дал ложное впечатление устранения проникновения: полный целевой spot check обнаружил у Ethan frame423 вершину mesh_0/4449 на −4,853 мм, хотя выбранный минимум был 0. Вес этой вершины: .780392 RightFoot + .219608 RightToeBase. Этот результат не скрыт: весь прежний набор и исходники сохранены в `run2-abc-sampled/`, включая отрицательный `full-shoe-spot-check.json`.

Исправлена причина: источник min заменён на все weighted вершины; cap, tau, исходные клипы и настройки B не менялись. Выполнен один новый 8-секундный A/B/C прогон. Потребность C оказалась 11,2197 /18,4100 мм. Измеренные изменения XZ и local bone TRS —0. Погрешность проверки общей Y-трансляции по округлённым 64 точкам меньше 0,1 мкм.

## Шов исходного цикла

На независимой клонированной модели A проиграны точные t=0 и t=duration через LoopOnce. Сравниваются мировые положения/повороты 80 костей после удаления линейного Hips XZ. Это проверка C0-позы, не скорости и не перцептивной плавности.

|---|---:|---|---:|---:|
| Emma | 6.4744 | Bip01_ROuterEyebrow | 1.3750° | 0.1037 |
| Ethan | 10.2633 | mixamorigRightHandMiddle3 | 0.8667° | 0.1064 |

Небольшой шов общего скелета остаётся, прежде всего в лицевых костях Emma и пальцах правой кисти Ethan. Полная бесшовность не заявлена. Дополнительный сглаживатель в рамках опыта не добавлялся.

## Закреплённый инструмент и проверки

FootIK: [hh-hang/three-player-controller](https://github.com/hh-hang/three-player-controller), commit `29403c7dcc48c43153c2d6126571e685ca012617`, версия 0.6.3, MIT. Upstream bundle не изменён. Минимальный host использует реальные публичные lifecycle/getter методы; полный PlayerController не требуется. Сцена сохраняет метры, номинальные сантиметровые расстояния upstream переводятся через distanceUnitMeters=.01. Размеры proxy-подошвы измерены один раз в rest-позе до испытаний, без подбора по результатам.

Финальный полный прогон: JS/console/HTTP ошибок нет, index.html и motion-lab.js проверкой не менялись. Оба финальных PNG визуально просмотрены; A/B/C метки различимы, панели и кадры целые. Отдельный synthetic smoke реального FootIK тоже прошёл, но он не заменяет проверку обуви. Fixed-step измерения не являются обещанием производительности 60 fps.

## API и файлы

Страница в изолированном репозитории: `review/exhibition-25-years/motion-lab/contact-bench.html`; запуск через HTTP из корня репозитория. Three и vendor локальные.

```javascript
await motionLab.whenReady();
// После contactBench.isReady === true:
await contactBench.setup("emma"); // или ethan
contactBench.reset();
contactBench.step(1 / 60);
contactBench.snapshot();       // без повторной постобработки
contactBench.frame(81);        // reset и последовательный replay
contactBench.seamCheck();      // независимая клонированная A, t0 и tT
contactBench.run(8, 1 / 60);    // metadata, summary и все 480 кадров
contactBench.play();
contactBench.pause();
```

CLI: `py -3 tools/qa_contacts.py --repo <корень лабораторного репозитория> --evidence <каталог отчёта>`. Временный localhost сервер и изолированный headless Edge закрываются после проверки.

Фактические отчёты Lenovo: `work/avatar-motion-data-20261122/evidence/contacts/`. Основные файлы: `summary.json`, `contact-summary-compact.json`, оба `*-contact-trial.json`, оба `*-seam-check.json`, два PNG и соответствующие frame JSON. Прежние прогоны — `run1-ab-initial/` и `run2-abc-sampled/`; старый отрицательный spot check относится именно к sampled-C версии.

«Best/worst» — иллюстрации max абсолютного full-shoe minY B среди стоп с эвристической plant-фазой, не оценка общей естественности. Финальные кадры: Emma 36 /0,60 с /0,1142 мм и Emma 81 /1,35 с /34,2486 мм.
